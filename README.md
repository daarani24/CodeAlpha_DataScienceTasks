# CodeAlpha Data Science Internship Projects
This repository contains the projects completed during my **Data Science Internship at CodeAlpha**. These projects focus on Machine Learning, Data Analysis, Data Visualization, and Predictive Modeling using Python.

## Projects

# 1. Iris Flower Classification
Built a machine learning model to classify Iris flowers into different species based on sepal and petal measurements.

# Skills Used:
* Data Preprocessing
* Classification Algorithms
* Model Evaluation
* Data Visualization
---

# 2. Car Price Prediction
Developed a regression model to predict car selling prices using features such as present price, fuel type, transmission type, kilometers driven, owner history, and car age.

# Result:
* R² Score: 95.81%
* MAE: 0.64
* RMSE: 0.98

# Skills Used:
* Feature Engineering
* Regression Models
* Data Visualization
* Model Evaluation
---

# 3. Sales Prediction
Built a sales prediction model using advertising expenditure data from TV, Radio, and Newspaper marketing channels.

# Skills Used:
* Linear Regression
* Data Analysis
* Feature Selection
* Sales Forecasting

# Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
