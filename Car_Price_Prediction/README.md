# Car Price Prediction using Machine Learning

# Objective
To predict the selling price of a car using machine learning regression techniques.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Exploratory Data Analysis
5. Model Training
6. Model Evaluation
7. Price Prediction

# Model Used
Random Forest Regressor

# Evaluation Metrics
- R² Score
- MAE
- RMSE

# Outcome
The model predicts car prices based on vehicle features such as present price, kilometers driven, fuel type, seller type, transmission type, owner history, and car age.
